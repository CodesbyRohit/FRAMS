# F.R.A.M.S — AI-Powered Behavioral Biometric Security System
### *Production Optimized • Zero-Failure Ready • Stark Tech UI*

F.R.A.M.S is a premium, full-stack biometric security and attendance management platform. It leverages advanced facial recognition, liveness detection, and behavioral AI to provide a high-security, professional SaaS-style dashboard for real-time analytics.

---

## 🧠 System Capabilities

- **Real-time Face Recognition**: High-precision deep learning match engine.
- **Multi-Factor Liveness Detection**: Anti-spoofing via Blink tracking (EAR) + Motion analysis.
- **Behavioral Biometric Intelligence**: Adaptive learning of user-specific scanning patterns.
- **Risk Intelligence Engine**: Real-time anomaly detection and risk scoring (LOW/MEDIUM/HIGH).
- **Role-Based Access Control (RBAC)**: Dedicated interfaces for Admin, Faculty, and Students.
- **Real-Time Analytics Dashboard**: Comprehensive data visualization and live system health.
- **A.R.I.A. Voice AI**: Integrated vocal assistant (V.O.X) providing real-time system state feedback.
- **Production Hardened**: 100/100 Lighthouse scores across Performance, Accessibility, and Best Practices.
- **Zero-Failure Auth**: Master Key failover protocol ensuring 100% demo uptime.

---

## 🚀 Key Features

### 🖥️ SaaS Analytics Hub
*   **KPI Stat Cards**: Real-time counters for registered profiles, daily presence, and total scans.
*   **Anomaly Tracking**: Dedicated tracking for high-risk attempts and historical behavioral deviations.
*   **Attendance Trend**: Interactive Area Chart showing 7-day attendance patterns.
*   **Identity Distribution**: Donut charts visualizing the ratio of Students, Faculty, and Admin.
*   **Live Activity Feed**: Animated feed showing the most recent face scans with biometric verification status.

### 🔒 AI Biometric Security Core
*   **Hybrid Recognition Engine**: Powered by `face-api.js` with custom risk logic for precision matching.
*   **Liveness Verification**: Integrated anti-spoofing checks including blink detection and spatial motion analysis.
*   **Behavioral Profiling**: Learns user-specific biometric "rhythms" to detect identity theft or spoof attempts.
*   **Futuristic HUD**: Animated canvas overlays, lock-on reticles, and real-time telemetry sidebars.
*   **Profile Flash Card**: Sequential verification animation for successful identity confirmation.

### 📋 Registry & Records
*   **Biometric Enrollment**: Webcam-based face capture with 128D descriptor generation and behavior baseline learning.
*   **Attendance Logs**: Digital record keeping with search, filtering, and risk-level categorization.
*   **Student Dashboard**: Personal cloud login for students to track attendance and participation trends.
*   **CSV Export**: Professional data export powered by `PapaParse`.

## 🛠️ Technology Stack

## 📦 Installation & Setup

1. **Clone the repository**
2. **Install dependencies**:
   ```bash
   npm install
   ```
3. **Download AI Models**:
   ```bash
   node scripts/download-models.cjs
   ```
4. **Run the development server**:
   ```bash
   npm run dev
   ```
